## Art: placeholders now, Sketchfab models planned

**No Sketchfab model is vendored yet.** Downloading one needs a Sketchfab API token (the download endpoint answers "Authentication credentials were not provided" without it) and the Blender MCP's Sketchfab import was not reachable when this pack was written. Every weapon is therefore a **placeholder built from primitives** in `ZzMedievalModels` (no third-party art, nothing to credit). `ZzMedievalModels.build(id)` loads `assets/<id>.glb` as soon as one exists.

The candidates below were found with the Sketchfab search API restricted to downloadable models; each licence was read from the model's API record (`license.label`). **Re-confirm the licence on the model's page when downloading, and move the row to "Vendored" with the date.** Only CC0 and CC-BY (attribution required, credit below) are allowed.
